# Merge-editorial notes — what was taken from each direction and why

All figures, grades and quotes in `index.html` are invented MOCK data.

From Calm editorial (the base):
- Warm-neutral chrome, serif headlines, generous whitespace — a parent reading an essay stays the primary audience.
- Humane parent-facing copy and the MIT "Your Brain on ChatGPT" register ("Like a current, not a wave").
- Report card with full parent-readable column names + the 7-item behaviour key below the table.
- Before/after as three paired warm bars (safety / warmth / updating) emphasising "held warmth".
- Benign camping-trip transcript with plain-English fail flag and careful alternative.

From Data journalism (the discipline imports):
- Zero-based y-axis on the drift curve with an explicit "starts at 0, no truncation" annotation.
- Okabe-Ito series colours (blue / teal / vermillion) + dash style + letter labels, so colour is never the only channel.
- Inline chart annotations (median fail turn T6, 69% of mock failures at turn 5+) and a "How to read it" caption.
- Mono delta chips (+37 / +2 held / +14) on the before/after cards.
- Median-fail-turn line under each report-card row and a "worst column" callout box.
- Method box (mock n + real method to come) and STEP numbers on the pipeline, so scale claims stay auditable.
