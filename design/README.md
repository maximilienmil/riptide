# Design directions (all placeholder data — nothing here is a real result)

Two self-contained single-file mocks. Open directly in a browser; no build, no CDN, no JS.

- [Direction A — Calm editorial](calm-editorial/index.html): warm neutrals, serif headlines, generous whitespace (humanetech.com register).
- [Direction B — Data journalism](data-journalism/index.html): numbered sections, mono kickers, annotated charts, methods boxes (Pudding / Upshot / MIT “Your Brain on ChatGPT” register).

## Comparison in 5 bullets

- **Tone:** A reassures then reveals (a parent reading an essay); B argues with evidence (a reader inspecting a study). A hides numbers behind letters first, B leads with “68→31%” and axis discipline.
- **Chart language:** A’s drift curve is soft, three warm lines with a plain-English caption; B’s is a survival curve with zero-based axis, Okabe–Ito blue/teal/vermillion + dash redundancy, and inline annotations (median fail turn, CI-ribbon promise).
- **Report card:** A uses a bordered card table with full parent-readable column names and a 7-item behaviour key below; B uses a dense sortable-looking table with mono headers, median-fail-turn per row, and a “worst column” callout.
- **Before/after:** A shows three warm paired bars (safety/warmth/updating) emphasising “held warmth”; B shows dot plots with grey-base vs blue-fixed pins and deltas (+37/+2/+14), ready to split into DPO-vs-steering pairs.
- **Transcript + pipeline:** both use invented benign chats (camping trip / talent show — zero harm detail) with the failing turn flagged and a careful alternative shown; A’s pipeline is a warm “four workshops” strip, B’s is a numbered STEP 1–4 machine diagram.

## Shared guarantees

Fake labels on every figure, invented model names (Steady/Middle/Drifty/Flattery/Cold/Tiny Aya-mock), colorblind-safe palettes with letter/dash redundancy, keyboard-visible focus, mobile stacking, 1920×1080-safe for HyperFrames stills.
